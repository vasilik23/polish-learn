# Accessibility audit

Дата первого аудита: 31 августа 2026. Цель — WCAG 2.2 Level AA на ключевых
сценариях. Автоматический score помогает находить дефекты, но сам по себе не
является заявлением о полном соответствии.

## Область проверки

- вход и восстановление аккаунта;
- «Сегодня» и «Задания»;
- выбор уровня и урока;
- библиотека и чтение текста;
- личный словарь и SM-2 практика;
- аудиопилот;
- профиль и меню пользователя.

## Исправления первого прохода

- Добавлена ссылка «К основному содержимому», доступная первой с клавиатуры.
- Для ссылок, кнопок, полей, select, textarea и summary введён единый заметный
  `:focus-visible` в светлой и тёмной темах.
- Основные action-кнопки получили отдельный контрастный цвет; до исправления
  Lighthouse фиксировал 2,5:1 для белого текста кнопки входа в тёмной теме.
- Каждая запись аудиопилота получила раскрываемую текстовую альтернативу с
  польским словом и смысловой подсказкой. Пользователь сам решает, раскрывать
  её или выполнять задание только на слух.

## Матрица ручной проверки

| Критерий | Метод | Статус |
| --- | --- | --- |
| 1.4.3 Contrast (Minimum) | Lighthouse + обе темы | повторить после deploy |
| 1.4.10 Reflow | 320 CSS px и 200% zoom, без горизонтального scroll | повторить после deploy |
| 1.2.1 Audio-only | текстовая альтернатива для каждой записи | реализовано |
| 2.1.1 Keyboard | Tab/Shift+Tab/Enter/Space на ключевых сценариях | повторить после deploy |
| 2.4.1 Bypass Blocks | skip-link переводит фокус к `main` | реализовано |
| 2.4.7 Focus Visible | контрастный focus ring | реализовано |
| 3.3.2 Labels or Instructions | labels, hints и названия controls | проверить |
| 4.1.2 Name, Role, Value | semantic snapshot и automated audit | проверить |

После deploy нужно заполнить статусы фактическими результатами desktop/mobile,
сохранить известные ограничения и не заявлять WCAG AA, пока вся матрица не
закрыта.

Основание: [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
